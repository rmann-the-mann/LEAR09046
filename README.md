Recognition of Prior Learning Portfolio Website
This is a static website. Upload the full folder to any static web host (GitHub Pages, Netlify, Cloudflare Pages, or an institutional web server).
To preview it locally, open a terminal in this folder and run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
The site is responsive, keyboard accessible, print-friendly, and includes image enlargement for portfolio evidence. All portfolio text and images are drawn from the supplied Word document.
